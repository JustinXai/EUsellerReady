# 05 - Provider Outreach Strategy

## Goal

Connect EUReadySeller visitors with qualified EU compliance service providers. Provider matching is a key revenue/utility feature of the site.

## Current State

The `/request-eu-compliance-quotes/` page collects lead form submissions via mailto. This is a placeholder.

## Phase 2 Provider Matching Options

### Option A: Email distribution list
- Collect submissions → forward to a curated list of providers via email
- Pros: Simple, no platform needed
- Cons: Manual management, no competition

### Option B: Provider portal (Phase 2+)
- Providers register on a portal, set their topics and countries
- Sellers submit requests → distributed to relevant providers
- Pros: Self-service, competitive quotes
- Cons: Requires backend + auth

### Option C: Integration with existing platforms
- Integrate with existing compliance marketplaces or lead gen platforms
- Examples: SellerSprite (Amazon), Helium10, Kompyte
- Pros: Existing traffic and provider network
- Cons: Platform dependency

## Recommended Approach (Phase 2)

1. Start with email distribution (Option A) — launch quickly
2. Build a simple Notion/Airtable pipeline to manage provider list
3. When volume justifies, build a provider portal (Option B)

## Provider Qualification Criteria

Before adding a provider to the network:
- [ ] Provides GPSR / EU RP / EPR services for ecommerce sellers
- [ ] Has verifiable business registration in EU
- [ ] Offers services in English (minimum)
- [ ] No history of compliance claim violations
- [ ] Clear pricing model (per-product, annual, or hybrid)
- [ ] Responsive to inquiries within 48 hours
