# EUReadySeller GSC Workflow

## Use GSC first
Start with GSC signals to identify which pages are gaining impressions, clicks, and better positions.

## Validate with Semrush
Use Semrush to confirm search volume, keyword difficulty, CPC, and intent before deciding what to change next.

## One focused page per sprint
Only make one focused page change per sprint unless the user explicitly requests a broader task.

## Protect growing pages
Do not repeatedly edit current winners unless GSC shows a clear reason to do so.

## Submit only changed URLs
After publishing, submit only the changed or new URLs to GSC rather than resubmitting the whole site.

## Keep the feedback loop
Monitor post-release GSC movement, compare with live behavior, and use that evidence to decide the next sprint.
